로컬 저장과 AI 전송은 다릅니다. 프롬프트·문서 텍스트·평가 결과는 지정한 내 PC JSON 파일에 저장합니다. AI 실행을 누르면 선택한 Codex/Claude 제공자에게 해당 자료 내용이 전송됩니다. 기밀 회사 자료는 회사의 외부 전송 허가가 있을 때만 사용하세요. 자격요건·낙찰확률을 AI가 확정하지 않습니다.

시작하기

왼쪽에서 공고를 새로 만들거나 기존 공고를 선택하세요. 최초에는 아무 자료도 AI에 전송되지 않습니다.

수정 데이터도 로컬 JSON 저장

파일 바이너리는 보관하지 않고 로컬에서 추출한 텍스트만 JSON에 기록합니다. 최대 10 MiB/파일, 6개 파일, PDF 40페이지·OCR 12페이지. 한국어 Tesseract 언어팩 필요. 수식은 저장된 계산값을 사용하며 매크로는 실행하지 않습니다. OCR 및 추출 누락은 경고로 표시합니다.

    1. AI가 영향인자 초안 작성

    선택해서 명시적 전송

    실행 전에 내 PC에 Codex / Claude CLI를 설치하고 각 계정으로 로그인해야 합니다. 설치되어 있지 않거나 로그인할 수 없으면 결과가 생성되지 않습니다. 두 CLI를 선택하면 독립 검토 결과를 표시하며, 실제 상호 반론을 하는 LangGraph 단계는 후속 개발입니다.

    2. 필수 참가조건 확인

    Hard Gate 8개
    AI 초안은 미확인 상태이며 검증 완료가 아닙니다. 참가자격 충족은 담당자가 원문과 증빙을 확인하고 '내가 확인함'을 선택해야 합니다.

    3. 전략·경쟁력 영향인자

    12개 · 가중치 100 (예시)
    점수는 1~5, 미확인은 비어있음. 근거가 없으면 검증할 수 없습니다. 예시 가중지표는 실제 수주 확률이 아닙니다.

    4. 사람의 최종 결정

    AI 권고와 사용자의 결정은 별개입니다. AI 분석은 계약 체결, 입찰서 제출, 실제 낙찰 결과 갱신을 수행하지 않습니다.
