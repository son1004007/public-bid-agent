# 공공 AI 입찰 분석 에이전트 (Public Bid Agent)

> **현재 상태: 기획 및 설계 단계**  
> 아직 서비스 구현, 테스트 및 공개 배포가 완료되지 않았습니다.

## 프로젝트 소개

나라장터에 공개된 AI 및 소프트웨어 관련 입찰공고를 검색하고, 공고문과 제안요청서(RFP)의 요구사항을 분석해 사용자 또는 기업의 기술 역량과 참가조건에 얼마나 부합하는지 검토하도록 돕는 웹서비스입니다.

단순히 키워드가 포함된 공고를 나열하는 대신, **어떤 조건이 적합하고 무엇을 추가로 확인해야 하는지 공식 자료의 근거와 함께 제시하는 것**을 목표로 합니다.

## 해결하려는 문제

공공 AI 사업에 참여하려면 여러 공고를 검색하고 제안요청서에서 참가자격, 기술 요구사항, 사업기간, 제출기한 등을 확인해야 합니다. 이 프로젝트는 반복적인 탐색과 검토 과정을 AI 에이전트로 지원하도록 설계했습니다.

## 주요 기능 (구현 예정)

1. **공고 검색**: 조달청 공개 API에서 AI/SW 관련 입찰공고를 조회합니다.
2. **문서 분석**: 공고문과 제안요청서의 참가요건 및 기술 요구사항을 추출합니다.
3. **적합성 비교**: 사용자가 등록한 기업·기술 정보와 요구사항을 비교합니다.
4. **추가 확인 질문**: 중요한 정보가 부족하면 임의로 판단하지 않고 질문합니다.
5. **근거 제시**: 적합, 추가 검토 필요, 부적합 등의 분석 결과에 원문 근거를 연결합니다.
6. **사용자별 관리**: Google 로그인과 사용자별 분석 내역 관리를 지원하도록 설계합니다.

위 기능은 **계획된 범위**이며 현재 구현 완료를 의미하지 않습니다.

## 서비스 이용 흐름

```text
사용자 로그인
    ↓
기업 및 기술 역량 입력
    ↓
나라장터 AI/SW 입찰공고 검색
    ↓
공고문 및 제안요청서 분석
    ↓
참가요건과 기술 역량 비교
    ↓
정보가 부족하면 추가 질문
    ↓
적합 / 추가 검토 필요 / 부적합
    ↓
공식 원문 근거와 함께 결과 표시
```

## 기술 구성 (설계 기준)

| 영역 | 적용 예정 기술 | 목적 |
|---|---|---|
| 웹 화면 | React, TypeScript | 검색 및 분석 결과 제공 |
| 백엔드 | Python, FastAPI | API, 인증, 데이터 처리 |
| AI 작업 흐름 | LangGraph | 검색·분석·질문·결과 생성 단계 제어 |
| AI 연동 | LangChain | 문서 검색 및 모델 연동 |
| 데이터베이스 | PostgreSQL, pgVector | 공고·사용자·문서 검색 데이터 관리 |
| 외부 도구 | MCP 적용 검토 | 공공데이터 검색 도구 연결 |
| 인증 | Google 로그인 | 사용자 식별 및 접근 통제 |
| 결과 전송 | SSE | 분석 진행상황 전달 |
| 실행 환경 | Docker Compose | 개발 및 실행 환경 구성 |
| 품질 검증 | pytest, 프런트엔드 테스트, GitHub Actions | 자동 테스트 및 검증 |

추론 모델은 Codex 활용을 우선 검토하지만, 공개 웹서비스에서 사용자별 ChatGPT/Codex 계정 연결이 지원되는지는 공식 정책과 기술 조건 확인 후 결정합니다.

## 설계에서 중점적으로 고려한 사항

- **근거 추적성**: AI 해석과 공고 원문을 구분하고 판단 근거를 확인할 수 있도록 설계
- **보안**: 외부 문서의 악성 지시, 임의 URL 접근, 인증정보 노출 및 사용자 간 데이터 접근 방지
- **신뢰성**: 외부 API 장애, 정보 누락, 중복 공고, 잘못된 모델 응답을 구분
- **검증 가능성**: 기능별 요구사항과 테스트를 연결하고 구현·검증 상태를 별도로 기록
- **유지보수성**: 파일별 한글 설계 계약을 먼저 작성하고 설계에 따라 구현
