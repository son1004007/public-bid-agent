# 공식 공고 웹 검토 우선순위 수직 슬라이스 - 2026-10-12

## 제품 목표
최종 목표는 나라장터 공고 수집 → 상세/RFP 전체 과업 분석 → 부서 역량·실적·인력/원가 대조 → 추천 순위 및 원문 근거 → 사람의 Bid/No-Bid 결정이다. 이번 변경은 read-only 검토 우선순위 단계이며 실제 참가자격·이익·수주가능성을 확정하지 않는다.

## 현재 구현
- GET /api/dashboard/recommendations: 기존 전체 공식 공고와 부서 프로필을 읽어 마감 전 OPEN/REGISTRATION_REVIEW 공고의 검토 우선순위 상위 30건만 반환.
- 문서 추출 성공 + 관심분야 RFP 발췌 근거를 가장 우선하고, 그 다음 본문 추출 확인·메타데이터 후보·REVIEW 재발굴 공고 순으로 배치. 원본 데이터는 제목만으로 제거하지 않으며, 마감·취소/담당자 불참 확정은 검토 후보에서 제외.
- 매 요청 시 현재 날짜를 기준으로 공식 공고 마감 여부 재평가. 로컬 대시보드·인력·원가·키 파일 수정 없음.
- /decision-preview 수집관리 화면에 추천 검토 순위·근거종류·미검증 지위·기존 상세 이동 연결.
- 응답에는 RFP 본문/비공개 인력/급여/키 포함하지 않음. 법적 참가자격·기술 적합성·가용 인력·사업성 모두 UNVERIFIED. AI 모델을 호출하지 않으며 analysis_mode = RULE_BASED_READ_ONLY.

## 실제 데이터 read-only 검증
현재 저장 공고 2,223건, 현재 마감/부서 조건 상세검토 후보 111건, 반환 상위 30건, 현재 추천 대상에서 RFP 내용 근거 확보 0건. 실 데이터 원본 dashboard.json 및 부서 프로필 전후 SHA-256 동일. 이 수치는 전체 추출 성공 5건과 모집단/기한 조건이 달라 직접 비교하지 않는다.
