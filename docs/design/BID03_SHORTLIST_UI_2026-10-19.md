# BID-03 읽기 전용 후보 화면 계약

- 근거: DECISIONS D-20, BID-03. 위험 MEDIUM(API 소비/업무 상태 표시), 복구는 UI 변경 제거.
- `/decision-preview`의 기존 목록·상세·판단·이력을 유지하고 별도 `지금 검토 가능한 후보` 화면을 추가한다.
- 기존 `GET /api/dashboard/bid-now-shortlist`만 소비한다. 세 큐는 분야 일치, 역량 보완·수익성 검토, 사전등록 검토이며 총수와 표시 상한을 구분한다. 기본 큐는 분야 일치다.
- 서버 분류/근거/문서 위험/접수 상태를 텍스트로 표시한다. API에 없는 원본 마감 날짜는 추정하지 않는다. 마감·취소·구차수·STALE 등의 보류는 상태별 집계로 표시하며 원본 목록에서 삭제하지 않는다.
- 법적 적격·보완 후 마진·보완 가능성은 항상 UNVERIFIED, 사람의 최종 Bid/No-Bid 및 최신 공식 원문 확인 필요. 보완 가능성/공동수급 허용이나 이익 임계치를 만들어내지 않는다.
- 화면 진입/갱신마다 GET, 10초 timeout, 이전 결과 제거, 중복 요청은 취소하고 최신 요청만 반영한다. loading/empty/error/권한 거절을 구별하고 재조회 버튼을 제공한다. API 응답의 비공개 필드·오류 원문은 표시하지 않는다.
- 상세는 현재 목록에서 찾은 공고 ID만 기존 상세 경로로 연다. 큐와 목록 revision이 다르면 목록을 다시 읽은 후 큐 재조회를 안내한다.
- 검증: 합성 Node UI 계약 및 실제 임시 서버/Chrome 390px·1440px, 세 큐·보류·오류·0건·XSS·GET 불변성, 기존 목록/상세/수기 이력 회귀. 사용자 UI 인수/운영 반영/BID-04 실자료 검증과 구분한다.
- 독립 Codex 사전 설계 검토와 최종 읽기 전용 검수 결과는 별도 검증 보고에 기록한다. GO 전 커밋·푸시 금지.
