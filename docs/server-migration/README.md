## 설계 완성도

기본 설계·구현 순서는 준비됐지만 전체 상세 설계 완료는 아니다. 화면 시안/필드·권한표·실제 DB/API 세부 계약·운영 환경은 각 SM 카드 전에 구체화한다. [현재 화면 대응표와 남은 상세](08-current-screens-and-ui-references.md)를 확인한다. 설계 GO를 UI 승인·구현 완료로 해석하지 않는다.

## 문서 권위와 미정 사항

사용자 확정 결정은 DECISIONS.md가 원본이다. 여기의 화면·엔터티·역할은 구현을 위한 **설계 초안**이며 업무 권한 확정이나 UI 승인 자체가 아니다. 기존 BID 검증 결과와 H01/H02 자동 개발 검증 기록은 역사적 구현 증거로 유지한다. 미래 서버의 완료 근거로 재사용하지 않는다.

서버 실제 위치·도메인·접근망·운영 담당자·백업 보관기간·계정 발급 대상·업무 권한 범위·AI 공급자/전송 동의/예산은 미정이다. 특정 클라우드/외부 AI/회사 서버 사용을 자동 승인하지 않는다. 초기 구현은 합성 데이터·격리 환경에서 가능하다.
