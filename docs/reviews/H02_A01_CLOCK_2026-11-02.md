## 변경 이유와 계약

고정 마감일 2026-10-20 fixture에 실행일이 들어가 `CLOSED != OPEN`이 발생했습니다. 수정 전 동일 단일 테스트 실패를 재현했습니다.
`normalize(item, *, at=None)`는 시간대가 있는 datetime을 주입받아 KST로 변환합니다. 생략하면 현재 KST를 한 번 읽습니다.
동일 시각을 observed_at과 실제 마감 판정 경로에 전달합니다. naive datetime/비-datetime은 ValueError입니다.
fixture 마감일을 미래로 옮기거나 테스트를 삭제/skip하지 않았습니다. `procurement_filter.py`의 취소 우선, 정각 CLOSED,
등록기한 미확인 시 기존 처리, legal_eligibility UNVERIFIED는 유지합니다. 두 README를 코드와 같은 커밋에서 동기화했습니다.
