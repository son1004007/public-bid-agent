## 1차 독립 검토 근거

- 범위: Draft PR 개발 브랜치의 공개 코드 diff 및 합성 테스트만 검토. 실제 사용자 로컬 workforce.json/operations.json은 검토 모델에 보내지 않음.
- 독립 검토자: 로컬 Codex CLI / gpt-5.6-terra, 일회용 작업 폴더, read-only, stdin 공개 staged diff.
- 입력 지문 SHA-256: `be0557785d83428caed2723bf2f52cbaa9501c94d8f22abb4a95d858b7231994`
- 최초 입력은 현재 사용자 요구와 기능 diff만 포함. 검토자에게 구현의 합격/불합격 결론을 주지 않음.
- 원문 출력은 PC 비공개 검수 폴더에 따로 보관. 검토 결과가 곧 최종 출시 승인은 아님.

## 남은 위험과 출시 게이트

- 실제 팀원 보유기술·담당분야는 ASSUMED이며, 실제 가용 공수는 모두 UNKNOWN.
- 실제 비용에는 법정 부담금·퇴직급여·간접비 등이 미포함. 공식 참여자격 및 요구인력 충족 판정은 미구현.
- 앞선 RFP 배치에는 프로세스 간 JSON 경합 잔여 위험이 있으므로 독립 최종 통합 검수와 사용자 UI 승인 전 Draft PR을 main으로 병합하지 않음.
- 최종 테스트/CI 및 재검토 결론은 재실행 증거 확인 후 추가 기록.

## 2차 독립 재검토와 위험 처리

- 검토 범위: 최초 구현부터 1차 수정까지 전체 공개 소스 diff. 인력·원가 비공개 파일은 외부 전송하지 않음.
- 모델: Codex CLI gpt-5.6-terra, 별도 격리 폴더·read-only·ephemeral. 입력 SHA-256: `b3c4fae701c464a2b3f20a7d8b47759b5211e8c917f53e2ce4d4fecd5d97ba1b`.
- 수용: 임의 자유서술 담당분야를 범용 허용값으로 제한; 집계 API와 명시적 CSRF 기반 상세 조회 분리; 급여가정/월 총원가 basis 추가; 가용량 미정/급여가정 시 예상이익 null; MM 소수 정규화; 인원 0 상태 별도 표시; VERIFIED는 추후 증빙 계약 도입 전까지 입력 불허.
- 조건부 오해: 수집 관리 기존 대시보드의 화면 확장 자체는 사용자의 부서 인력 적용 최신 지시에 부합하며, 사용자 공고와 판단 이력 원본을 실제 변경했다는 증거가 아니다. 그래도 인력 상세 자동 조회는 금지했다.
- 저장 경계: server ROOT는 기본 home/.public-bid-agent-local, 실제 사용자 데이터 경로는 public repository 밖이다. workforce.load가 repo 내부 경로를 거부한다. 서버는 localhost만 bind, HOST 검사, POST Origin/CSRF 경계를 유지한다. 세션 없는 다른 사용자 접근 방지까지의 공개 서비스 인증은 범위 밖.
- 남은 문제: 실제 기술 경력·공수 자격/급여 부담률 미확인, RFP 배치 프로세스 간 JSON 쓰기 경쟁, 사용자 UI 승인 및 통합 독립 최종 검수 미완료. Draft/main 병합 HOLD.
