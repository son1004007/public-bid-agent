# 회사 공통 운영정보 및 공고별 원가계획 검증 (2026-10-10)

## 범위와 입력 위험

- 회사 공통 운영정보 `operations.json`: 직무별 월 총원가·가용 MM, 간접비율·위험충당률 및 8개 운영자료의 수집 상태/승인된 요약/자료명/검토일. 초기 입력은 빈 직무 목록과 미확인 자료 항목.
- 공고별 `cases.json`: 별도 `cost_plan`에 직무별 예상 MM/외주·직접경비·제안비/부가세 제외 예정 공급가액, `cost_estimate`에 산출·경고·사용한 운영 버전.
- **실제 회사/직원/고객 정보는 수집·전송하지 않았음**. Windows PC 합성 폴더 `%LOCALAPPDATA%\\PublicBidAgent\\Lab\\ops-cost-synthetic-e2e`에서 가상 기준만 저장하고 실행.
- `prompt_for`는 기존 공고 설명·첨부 텍스트만 직렬화, `operations.json`의 내용/공고별 원가계획을 자동으로 모델에 전송하지 않음. **사용자가 직접 프롬프트에 복사한 내용까지 자동으로 비밀검출/차단하는 기능은 없음**.
- 운영 JSON은 로컬 평문. 회사 정책 승인 없는 실자료 입력·개인급여/원본 인사/재무정보 저장은 금지. 원가 계산이 사용자 최종 입찰결정을 갱신하지 않음.

## 계산식 (VAT 제외)

- 직접인건비 = Σ(직무별 월 기업부담 총원가 × 예정 MM), KRW 정수 반올림.
- 직접 수행비 = 직접인건비 + 외주비 + 기타 직접경비.
- 간접비 = 직접 수행비 × 회사 설정 간접비율 (원단위 반올림).
- 위험충당액 = (직접 수행비 + 간접비) × 회사 설정 충당률 (원단위 반올림).
- 예상 총원가 = 직접 수행비 + 간접비 + 위험충당액 + 제안 준비비.
- 예상 사업이익 = 예정 공급가액 − 예상 총원가.
- 예상 사업이익률 = 예상 사업이익 / 예정 공급가액 × 100, 0.1%p 반올림.
- 공급가액 미입력·0원 또는 공수 0/단가 0·가용 MM 초과는 경고. 회사 사내 실제 회계·세무·현금흐름·경쟁 사업 간 인력 중복배정·낙찰확률의 검증/확정 기능이 아님.
