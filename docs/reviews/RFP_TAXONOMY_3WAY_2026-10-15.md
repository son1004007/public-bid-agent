# RFP 참가자격·평가기준·과업 분류 개선 및 실제 표본 검토

- 기준: 2026-10-15
- 사용자 결정: [DECISIONS.md](../../DECISIONS.md) D-16
- 범위: `local_app/rfp_requirements.py`의 보수적 문맥 규칙 및 자동 검사, `frontend/public/dashboard-live.js`의 유형 설명 문구
- 목적: 참가자격·평가기준·과업 요구사항의 **분류 오류 감소**. **RFP 요건 추출 완전성이나 법적 적격성 검증 완료가 아님**.
- 보안: 원본 RFP·개인/회사 인력·등록키·원본 해시 목록 등 비공개 데이터는 공개 저장소나 Codex 입력으로 전달하지 않음. 실제 RFP 검증은 개인 Windows PC 내부의 읽기 전용 스크립트로만 수행.

## 개선 사항

1. 기존 8개 후보 유형에 **평가기준·선정방식(evaluation)**을 추가해 **총 9개**, `schema_version=2`. 과거 API/화면의 8개 분류 계약과 구분.
2. `공동수급` 단어만으로 참가자격 후보가 되던 패턴을 제거. 공동수급 허용·구성·참여·협정 등 자격 문맥만 참가자격으로 허용. **공동수급체 구성원별 평가 점수 합산·동점 처리**는 평가기준으로 분리.
3. 평가기준에는 기술/가격/정량/정성평가·배점·득점·동점·협상/낙찰 선정방식·점수 산식을 탐지하고, **교육 서비스의 '퀴즈 점수 조회' 기능** 및 평가결과 승복 확인서 등은 평가기준 후보에서 제거.
4. 과업 요구사항은 구축·개발·연계·가공·검수·데이터 처리 등 실제 수행 표현을 유지하되 **평가 문맥/법률·하도급/계약변경·목차·연락처·기능요구사항 제목/표·사업 내용 이해도 평가** 등 단순 언급을 배제하도록 개선.
5. 기존 공식 첨부 식별·원본 SHA/추출 문자 위치·`page=null`·`STALE`/취소 차단·원문 읽기 전용·카테고리별 최대 5개·전체 후보 탐색 상한은 그대로 유지. 결과는 **텍스트 표현 후보**이며 참/거짓·필수 요건·사업 참여 적격 여부를 확정하지 않음.

## 분류 정확도 점검의 근거와 범위

### 합성 정답 사례

- `local_app/test_rfp_requirement_taxonomy.py`에 참가자격/평가기준/과업/무관 사례 및 혼합 문장, 동점·공동수급 오분류, 교육 서비스 점수·사업내용/평가 구분 등 **정답이 사전 지정된 문장**을 별도 회귀 테스트로 추가.
- 통과율은 **해당 합성 문장 정답 재현율**이며 일반 RFP의 Precision, Recall, F1을 의미하지 않음.
- `local_app/test_rfp_requirements.py`는 9개 유형, schema version 2, 본문 오프셋·문서 출처 무결성·정정/취소/STALE 차단 및 기존 HTTP 400/503 회귀를 확인.

### 실제 RFP 표본

- 2026-10-15 당시 로컬에서 현행·비STALE·본문 검증 캐시를 가진 공고 **65건** 중 ID 정렬상 균등 간격으로 **20건**을 선택해 **읽기 전용 분석**. 전체 저장 공고 3,777건의 대표 무작위 표본은 아니므로 모집단 일반화 금지.
- 최종 분류로 확보한 표본의 상한 내 후보는 **참가자격 93건, 평가기준 95건, 과업 요구사항 20건**. 각 유형은 공고마다 원문 후보 최대 5건이라 **전체 발생 빈도나 원문 요구사항 총수로 해석 금지**.
- 세 유형에서 공고에 걸친 표현을 각 12건씩 확인. 실제 RFP에서 **'공동수급체 평가 점수 합산'을 참가자격으로 오분류하던 문제**, **교육 기능의 '퀴즈 점수' 평가기준 오분류**, **과업 내용 변경·예산 조정/목차·하도급 안내의 과업 오분류**가 수정 뒤 억제됨.
- 남은 애매한 유형 예시: 참가자격 내 서류 증명/다른 공고문 참조, 평가기준 내 평가 절 제목, 과업 내 사업 배경·과업 소개. **이 표현들은 핵심 필수조건이 아니거나 문맥이 부족할 수 있음.**
- 정량 분류 정확도(Precision/Recall/F1) 산출에는 **공고별 RFP 원문 전체에 대한 독립 라벨링**이 필요. 이번에는 모델 출력 후보 위주 실사용 점검이므로 Recall 측정 불가. 조용히 제외되는 필수 과업/참가요건이 없다고 보증하지 않음.
- PDF/HWP 파서 한계·표와 각주 구조 훼손·최대 44,000자 캐시·2문서/공고·5후보/범주의 탐지 상한도 유지. 평가기준/과업 모두 원본 문서 직접 대조가 필요.
